5. 状态图（战场 BattleSnapshot.status）

WAITING / DRAW 在类型与 UI中存在（联机/归一快照）； 单机 Battlefield.reset 后直接进入 RUNNING，终态仅由 CombatJudger.updateBattleStatus 产生。 

stateDiagram-v2

  [*] --> Battling : solo reset enters here

  Battling --> Battling : tick battlefield update

  Battling --> RedWin : blue camp eliminated RED_WIN enum

  Battling --> BlueWin : red camp eliminated BLUE_WIN enum

  Battling --> NeutralFail : simultaneous combat loss FAILED enum

  RedWin --> [*]

  BlueWin --> [*]

  NeutralFail --> [*]

图中结点与源码枚举对应：Battling → RUNNING； RedWin → RED_WIN； BlueWin → BLUE_WIN； NeutralFail → FAILED。 WAITING / DRAW 未画入本图，参见上文说明。
