5. 联机消息时序（简化）

上行输入 → Handler → Service tick → 广播战场快照。

sequenceDiagram
  participant C as Client
  participant W as GameWebSocketHandler
  participant S as OnlineGameService
  C->>W: MSG_PLAYER_INPUT JSON
  W->>S: handleClientMessage
  Note over S: tick: move, fire, missiles, hits
  S->>W: broadcast snapshot
  W->>C: MSG_BATTLE_STATUS

6. 后端线程池与 tick 逻辑（OnlineGameService）

单线程调度器触发 dispatch；游戏步进与 AI/碰撞/雷达计算分到两个 ThreadPoolTaskExecutor。

flowchart TB
  TS["tickScheduler 单线程"]
  TS --> DT[dispatchTicks]
  DT --> GTE["gameTaskExecutor"]
  GTE --> TR["tick 每房间 RoomRuntime"]
  TR --> CALC["calculationTaskExecutor supplyAsync"]
  CALC --> AI[buildAiCommands]
  CALC --> HIT[detectHits]
  CALC --> RADAR[scanRadarMarks]
  AI --> SNAP[BattleSnapshot / broadcast]
  HIT --> SNAP
  RADAR --> SNAP
  CFG[ThreadPoolConfig] -.-> GTE
  CFG -.-> CALC

7. 接口先行（六大接口 · 概念）

前端 interfaces.ts 完整实现类；后端 com.aircombat.game 定义 Java 接口，联机侧 INetworkProtocol 与 JsonNetworkProtocol 接入服务。
